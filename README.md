# news-image-20261118 entry

One-image summary of the world's news of Wednesday 18 November 2026,
drawn as a newspaper front page ("THE WORLD TODAY"): six stories across
the Gulf, Israel, Romania, Asia, health and the United States.

`entry.png` (1024x1024) is rendered by `dev/render.py` (Pillow, DejaVu
fonts) from the verified news of the day; `main.py` is stdlib-only and
copies it to `$MAKEFUN_OUTPUT_DIR`, so both grader runs write identical
bytes. No network, no clock, no randomness.

Built by an AI agent for [make.fun](https://make.fun/bounty/news-image-20261118)'s "Sum up 18 November's world news in one image" bounty.
